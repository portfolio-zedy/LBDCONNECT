# LBD Nation Connect — Bethel | The Online Prayer House

Mobile-first church app (Next.js + Tailwind + shadcn/ui) with a
**Google Sheet as the backend database**. Pray · Grow · Connect · Fulfil.

## How it works

- **Users tab** of the Google Sheet holds every sign-in account (leader or
  member). Passwords are stored as scrypt hashes generated by the app.
- **Programmes / Teachings / Testimonies** tabs are read live — edit them in
  the sheet and the app picks the changes up within ~45 seconds.
- **Members tab** receives member registrations made by signed-in leaders
  in the app ("Register a Member").
- The Join Daily Prayers link is Zoom for signed-in leaders and the WhatsApp
  orientation platform for guests. It comes from `ZOOM_LINK` / `WHATSAPP_LINK`
  env vars when set, otherwise from the local SQLite fallback store.
- If the sheet is briefly unreachable, accounts fall back to a local SQLite
  store (schema auto-creates), and content modules show a friendly error.

## Local development

```bash
npm install          # or bun install
cp .env.example .env.local   # fill in the values
npm run db:push      # creates the local fallback SQLite file
npm run dev          # http://localhost:3000
```

## Deploying (Vercel, free)

1. Push this repo to GitHub.
2. On vercel.com → Add New → Project → import the repo (Next.js is auto-detected).
3. Add the environment variables from `.env.example` in Project → Settings →
   Environment Variables (GOOGLE_SHEETS_WEBAPP_URL, GOOGLE_SHEETS_SECRET,
   AUTH_SECRET, and optionally ZOOM_LINK / WHATSAPP_LINK).
4. Deploy. The sheet connection works immediately — no database setup needed.

## Android APK for demos

The site is an installable PWA (manifest + service worker included):

- **Quickest**: open the deployed URL in Chrome on Android → ⋮ menu →
  "Add to Home screen" — it launches full-screen like an app.
- **Real APK file**: go to pwabuilder.com, paste the deployed URL,
  Package for Stores → Android → download the signed APK and sideload it
  (Settings → allow install unknown apps).

## Accounts

There is no public sign-up. A signed-in leader creates accounts from the
**Leader Login** card → Leader Admin → Create account (role: leader or
member). Members do not sign in — they are registered into the Members tab.
